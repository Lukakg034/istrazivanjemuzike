# CLH-B01

Selected Western art music. File total: **11** (7 Verified, 4 Partially verified). Target was 80+. This file was kept small on purpose and is still far under the aim.

## What is in the file

Debussy (Clair de lune already present, plus Menuet and Passepied), Satie (three Gymnopédies), Villa-Lobos (*Bachianas Brasileiras* No. 5), Ginastera (*Danzas Argentinas*), William Grant Still (Symphony No. 1), Takemitsu (*November Steps*), and Coleridge-Taylor (*Hiawatha's Wedding Feast*). Genre Gymnopédie is the title's own form name. Impressionism on the Debussy rows is the catalogue label for that piano suite; the opened pages call the pieces a piano suite.

## Sources

Wikipedia work articles, the Internet Archive Fromont scan for *Suite bergamasque*, IRCAM, the Ginastera society, Library of Congress, Boston Symphony, and the New York Philharmonic note for *November Steps*. The Coleridge-Taylor page and a Kansas finding aid for the 1898 Novello score.

## Gaps

Opera arias, ballet, Romantic piano and symphony beyond this handful, minimalism, historical dances, and most contemporary classical music. A Chopin genre list was opened, but it does not state the composer's country, so those pieces were not added.
